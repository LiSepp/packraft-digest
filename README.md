# Packraft 资料库（packraft-digest）

老大的 packraft / 激流皮划艇资料库：一份长期有用的**精选阅读清单**，加上每天更新的**新增榜**（类似热搜）。全部中文说明，链接指向原始来源。

## 背景
- 主要在天津一带划 packraft，船是 MRS Nomad S1（平水/旅行型，带可拆尾鳍）。
- 物理知识库：[LiSepp/packraft-physics](https://github.com/LiSepp/packraft-physics)（计划做动画），本仓库里跟**稳性、偏航、读水/水流**相关的条目会特别标出 🧪，方便直接拿去当素材。
- 有 DJI Action 6 头顶视角的水上视频，可以和读水资料对照着看。

## 目录结构
```
packraft-digest/
├── README.md              # 本说明
├── reading-list.md        # 精选阅读清单（存量，长期有效，按类别分组）
└── trending/
    └── YYYY-MM-DD.md      # 新增榜（每天一份，最近一周左右的新内容，排名 1–10+）
```

## 两份清单怎么用
- **reading-list.md（存量）**：组织协会、安全救援、课程、书、视频频道、读水与流体物理、装备、水位工具、社区论坛。每条有链接和一两句“为什么有用”。标注“已推过”的是 2026-10-10 已经给过的资源。
- **trending/日期.md（新增榜）**：每天从 r/packrafting、r/whitewater、r/Kayaking、American Whitewater 新闻、品牌/博主的 YouTube 等抓新内容，按“对老大有用程度 + 热度”排名。每条写清标题、来源、日期（北京时间）、热度依据、一句话亮点和链接。

## 约定
- 只收录真实查到、能打开的资源，不编链接。
- 日期一律按北京时间（UTC+8）。
- 标记：🧪 = 对 packraft-physics 有用；🔁 = 已推过；⚠️ = 需要注意（比如疑似广告帖或机器人帖）。
